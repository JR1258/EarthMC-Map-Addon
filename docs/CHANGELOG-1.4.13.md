# 1.4.13

**EarthMC API key**
- EarthMC now requires an API key on its API, as of 19 November. Run `/api key copy`
  in game and paste it into Settings -> API Key -> EarthMC API Key. It is sent only to
  api.earthmc.net, is never written to the log, and survives "Reset All".
- Without one, everything the live map carries still works: borders, nation colours,
  town names, players, the imagery layer, hover, search, nation panels and capital
  stars, just with less available information on a few specific things.
- Or skip the copying entirely: "Get key from chat" writes the command out for you and
  saves the key the moment EarthMC answers, even when it arrives as a click-to-copy
  line with the key never shown on screen.

**Search**
- Your last ten searches sit under the search bar, newest first, and lead to wherever
  that town, nation or player is now. "Reset All" no longer clears them.

Available for Minecraft **1.21.11**, **26.1.x**, **26.2** and **26.3**.
